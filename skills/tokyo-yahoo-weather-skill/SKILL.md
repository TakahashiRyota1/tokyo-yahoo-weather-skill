# tokyo-yahoo-weather-skill Skill

## When to Use

- 東京の天気予報をYahoo天気予報から確認したいとき
- 天気確認の手順を毎回同じ流れで実行したいとき
- Yahoo天気の東京ページを素早く参照したいとき

## Procedure

1. Yahoo天気予報を開く。
2. 検索欄で東京を指定し、東京の予報ページを表示する。
3. 今日、明日、週間予報の順で必要な項目を確認する。
4. 気温、降水確率、降水量、風、注意報や警報を整理して伝える。
5. 必要なら時間帯別予報と週間予報を分けてまとめる。

## Pitfalls

- Yahoo天気の表示内容は地域や時間で変わるため、取得時点の画面を優先する。
- 東京でも市区町村単位で予報が異なる場合があるため、対象地域を明確にする。
- 広告や補助情報ではなく、予報欄の数値を読む。

## Verification

1. 東京の対象地点が合っていることを確認する。
2. 今日の最高最低気温と降水確率を確認する。
3. 週間予報で翌日以降の変化を確認する。

## Examples

- 例: 今日は東京の天気をYahoo天気で確認して、外出向けに要点だけまとめる。
- 例: 明日から3日分の東京の予報をYahoo天気から整理する。

## Exclude From This Skill

- 個人の予定
- 一回限りのURL
- ログイン情報
- スクレイピング用の固定トークン
