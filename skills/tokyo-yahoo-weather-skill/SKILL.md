# tokyo-yahoo-weather-skill Skill

## When to Use

- 東京の天気予報を複数のソースから確認したいとき
- 1つのサイトだけではなく、複数サイトを突き合わせて信頼性を高めたいとき
- 天気確認の手順を毎回同じ流れで実行したいとき
- 注意報・警報など、信頼性が重要な情報を確認したいとき

## Data Sources

| サイト | 特徴 | 優先度 |
|---|---|---|
| 気象庁（jma.go.jp） | 日本の公式機関。注意報・警報の最終情報源 | 最優先（特に警報系） |
| Yahoo天気（weather.yahoo.co.jp） | 時間帯別・週間予報が見やすい | 主要ソース |
| tenki.jp | 日本気象協会監修。指数情報（洗濯物・像・紳外線など）が豊富 | 補完ソース |
| ウェザーニュース（weathernews.jp） | ユーザー報告を含む体感天気に強い | 補完ソース |

## Procedure

1. 気象庁を開き、東京（区部・多摩地域等）の注意報・警報の有無を確認する。
2. Yahoo天気予報を開き、検索欄で東京を指定し、東京の予報ページを表示する。
3. 必要に応じてtenki.jpまたはウェザーニュースを開き、同じ地域の予報を確認する。
4. 今日、明日、週間予報の順で必要な項目を確認する。
5. 気温、降水確率、降水量、風、注意報や警報を整理する。
6. 複数サイト間で数値が大きく異なる場合は、気象庁の情報を優先し、他サイトの値は参考情報として併記する。
7. 必要なら時間帯別予報と週間予報を分けてまとめる。

## Pitfalls

- 各サイトの表示内容は地域や時間で変わるため、取得時点の画面を優先する。
- 東京でも市区町村単位で予報が異なる場合があるため、対象地域を各サイトで統一して明確にする。
- 広告や補助情報ではなく、予報欄の数値を読む。
- サイト間で降水確率や気温が数％～数℃程度ズレることがある。大きな乖離がある場合は値の平均ではなく、気象庁の公式値を優先する。
- 注意報・警報は気象庁発表が正であり、他サイトの表示は反映が遅れる場合がある。

## Verification

1. 東京の対象地点が全サイトで一致していることを確認する。
2. 今日の最高最低気温と降水確率をサイト間で突き合わせ、大きな乖離がないか確認する。
3. 週間予報で翌日以降の変化を確認する。
4. 注意報・警報がある場合は気象庁の発表内容を最優先で確認する。

## Examples

- 例: 今日は東京の天気を気象庁とYahoo天気で確認して、外出向けに要点だけまとめる。
- 例: 明日から3日分の東京の予報をYahoo天気とtenki.jpから比較して整理する。
- 例: 大雨警報が出ているかを気象庁で確認し、他サイトの予報と合わせて報告する。

## Exclude From This Skill

- 個人の予定
- 一回限りのURL
- ログイン情報
- スクレイピング用の固定トークン
